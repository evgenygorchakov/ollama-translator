# Ollama Translator

Расширение для Chrome и Firefox (MV3): перевод страниц EN→RU через локальную Ollama. Для личного
использования на Windows 11 и Linux, не публичное. План текущей работы, когда он есть, — в
`PLAN.md` (после завершения файл удаляется); работаем по нему этап за этапом, после каждого
этапа — короткий отчёт и чек-лист ручной проверки для пользователя.

## Правила
- Без сборки и без npm-зависимостей в рантайме. Background — ES-модуль, content scripts —
  обычные скрипты (общий namespace через `window.__ollamaTranslator`).
- Функции — независимые модули в своих папках (`page/`, `selection/`, `dub/`), общее у них
  только `src/lib/` и `src/shared/`. Новый функционал — отдельным модулем, который можно
  удалить целиком: папка, строка импорта в `src/background.js`, записи в манифесте. Общий код
  он использует через точки расширения, своего туда не вписывает.
- Чистая логика — в `src/lib/`. Если она нужна только новому модулю, то в его `lib/`
  (`src/dub/lib/`). Автотестов не пишем.
- Текст от модели вставлять только через `textContent`, никогда через `innerHTML`.
- Разработка нативно на Windows 11. Ollama доступна на `http://127.0.0.1:11434`. Перед
  `ollama pull` (это гигабайты) спрашивать пользователя.
- Silero (синтез речи для озвучки) — на `http://127.0.0.1:5011`. На Windows он ставится из
  `tools/silero/` (venv через uv, запуск вручную `start-silero.cmd`, по желанию — автозапуск
  задачей Планировщика «Silero TTS»), на Linux — systemd-сервис из `sup/optional/voice`. Если
  запущен WSL, порт может держать Silero из WSL (см. `tools/silero/README.md`). Перед установкой
  torch и моделей Silero (сотни МБ) спрашивать пользователя.
- Поведение в браузере проверяет пользователь: Claude даёт ему конкретный чек-лист.
- Код должен одинаково работать в Chrome на Windows и в Chrome/Chromium на Linux, а также
  в Firefox 140+. Один манифест на оба браузера: Chrome берёт `background.service_worker`,
  Firefox — `background.scripts` (тот же модуль как event page). Только API, общие для обоих:
  `chrome.*` в Firefox есть и возвращает промисы.
