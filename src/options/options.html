Ollama Translator — Settings

Ollama

For Ollama on another computer the extension will ask for permission to access this address. That Ollama also needs OLLAMA_ORIGINS=chrome-extension://*,moz-extension://*.

Web search in Ask freely

Searches go through your SearXNG server; answers use your selected Ollama model. No API key is needed. SearXNG must allow JSON search (search.formats: [html, json] in settings.yml). Check runs a sample search. Answers use search excerpts, not full page downloads. Requires a model with tool support and a context of at least 8192, set in Ollama.

Requests

Context length is managed in the Ollama app. The extension uses the loaded model's context and shows token usage in the popup and next to answers. More than 1 parallel request only helps if the model fits entirely in VRAM (ollama ps → 100% GPU) and OLLAMA_NUM_PARALLEL is set.
Advanced: custom system prompt

Leave empty for the built-in prompt (shown in gray). {targetLang} is replaced with the language name. The model must return JSON {"translations": [...]}: the response format is enforced by a schema, but it is better to mention it in the prompt too.

Video dubbing

Speech synthesis server: tools/silero on Windows, the systemd service from sup/optional/voice on Linux. Dubbing is always in Russian, the translation language doesn't affect it.

Original volume, speech speed-up and Russian subtitles are in the menu next to the “Translate” button in the YouTube player.
