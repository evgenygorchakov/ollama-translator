Ollama Translator — настройки

Ollama

Для Ollama на другом компьютере расширение попросит разрешение на этот адрес. Там тоже нужен OLLAMA_ORIGINS=chrome-extension://*,moz-extension://*.

Запросы

Параллельность больше 1 имеет смысл, только если модель целиком в VRAM (ollama ps → 100% GPU) и задан OLLAMA_NUM_PARALLEL.
Продвинутое: свой system prompt

Пусто — встроенный промпт (показан серым). {targetLang} заменяется на название языка. Модель обязана вернуть JSON {"translations": [...]} — формат ответа задаётся схемой, но в промпте его лучше тоже упомянуть.

Озвучка видео

Сервер синтеза речи: на Windows — tools/silero, на Linux — systemd-сервис из sup/optional/voice. Озвучка всегда на русском, язык перевода на неё не влияет.

Громкость оригинала, ускорение речи и русские субтитры — в меню рядом с кнопкой «Перевести» в плеере YouTube.
