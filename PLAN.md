# Ollama Translator — план: краткое содержание видео YouTube

На странице видео YouTube кнопка «Краткое содержание» в popup и пункт меню «Краткое содержание
страницы» открывают ту же панель, что и для страниц. Только текстом для модели служит
расшифровка речи из субтитров видео, а не текст страницы. «Коротко / Подробно», вопросы по
тексту, длинный текст по частям и «Стоп» работают так же.

Работаем этап за этапом. После каждого этапа — короткий отчёт и чек-лист ручной проверки.

## Решения (поменять до начала этапа)

| Вопрос | Решение |
|---|---|
| Где работает | `www.youtube.com/watch`. Shorts (у них другой плеер), трансляции, встроенные плееры на других сайтах и `m.youtube.com` — нет |
| Как запустить | Как для страницы: кнопка «Краткое содержание» в popup и пункт «Краткое содержание страницы». На странице видео они делают краткое содержание видео. Отдельной кнопки в плеере нет: панель в плеере — часть озвучки, а модули не связываем. Описание и комментарии — через «Кратко о выделенном», как раньше |
| Какой текст | Субтитры видео — расшифровка речи. Дорожка: ручные на языке речи (язык автоматических) → автоматические → дорожка плеера по умолчанию → первая в списке. Машинный перевод субтитров YouTube не берём. Неречевое (`[Music]`, `♪`) убираем, как в озвучке |
| Текст для модели | Строка — кусок речи до паузы от 1,5 с или до смены говорящего, новый говорящий — с `>> `. Длинную строку режем по концу предложения. Меток времени нет (этап 2). Заголовок — название видео из плеера |
| Нет субтитров | «У видео нет субтитров — сокращать нечего», без запроса к модели и без «Повторить». По описанию видео краткое содержание не делаем |
| Язык | `targetLang` из настроек. Видео может быть на любом языке |
| Промпты | Свои слова для видео во всех промптах (итог, заметки, сведение, вопросы, поиск по частям): «расшифровка речи из субтитров видео; в автоматических субтитрах бывает нет пунктуации и есть ошибки распознавания — понимай по смыслу; `>>` — сменился говорящий» вместо «текст с веб-страницы, в нём меню и реклама». Выделенное — по-прежнему со словами для страницы |
| Длинное видео | Как длинная страница: части, заметки, кэш заметок. Час речи — около 55 000 символов, при num_ctx 8192 это примерно 4 части. Предел 150 000 символов — около 2,5–3 часов |
| Надписи панели | «Краткое содержание видео», «Загружаю субтитры…», «Видео длинное — читаю по частям», «Учтено начало видео», «Учтены все субтитры», «Спросить о видео…». Внизу — какие субтитры взяты: «Субтитры: автоматические, en» |
| Переход к другому видео | YouTube меняет видео без перезагрузки страницы. Панель остаётся и относится к прежнему видео, вопросы — тоже к нему. Для нового видео открыть панель заново |
| Полный экран | Панель вне плеера и в полноэкранном режиме не видна — так и оставляем |
| Не делаем | Кнопку в плеере, главы и описание видео, распознавание речи без субтитров, перевод субтитров YouTube |

## Устройство

Загрузка субтитров сейчас в модуле озвучки (`src/dub/page-captions.js`, `parseJson3` в
`src/dub/lib/captions.js`), а модуль краткого содержания из `dub/` брать не может. Переносим её в
общий код `src/lib/`, и оба модуля берут её оттуда. Разбиение на фразы для озвучки (`toPhrases`)
остаётся в `dub/`.

```
src/lib/
  youtube-captions.js   pageCaptions(videoId, lang) — функция для executeScript в мире
                        страницы (без изменений, кроме выбора дорожки и названия видео);
                        parseJson3(json) — json3 → слова со временем и сменой говорящего
src/summary/lib/
  transcript.js         слова → текст для модели (строки по паузам и говорящим)
```

`pageCaptions(videoId, lang)`: `lang` — `"en"` у озвучки (как сейчас: ручные английские, иначе
автоматические), `null` у краткого содержания (дорожка по таблице выше). В ответе добавляется
`title` — название видео.

```
вкладка (главный фрейм)                         service worker
┌───────────────────────────┐                   ┌──────────────────────────────────────┐
│ summary/panel.js          │  порт "summary"   │ summary/background.js                │
│  open({ kind: "video",    │ ── transcript ──▶ │  executeScript(MAIN, pageCaptions)   │
│        videoId })         │ ◀─ transcript ─── │  parseJson3 → transcript.js → текст  │
│  дальше — как с выделенным│ ── summarize, ──▶ │  как для страницы, промпты для видео │
│  текстом                  │    ask { kind }   │                                      │
└───────────────────────────┘                   └──────────────────────────────────────┘
```

- `openPanel` в `summary/background.js` по адресу вкладки (`tab.url`, доступен по activeTab)
  решает, что открыть: на `/watch` — `{ kind: "video", videoId }`, иначе — страницу.
- Порт: новый запрос `transcript { videoId }` → `transcript { title, text, kind, lang }`, где
  `kind` — `asr` или `manual`, либо `error { code, message }`. Коды — как у `pageCaptions`;
  `NO_CAPTIONS` и `LIVE` панель показывает без «Повторить».
- У `summarize` и `ask` новое поле `kind`: `"video"` — промпты для видео, иначе для страницы.
  `kind` входит в ключ кэша заметок.
- Субтитры загружаются сразу при открытии панели, в рамках activeTab. Права YouTube из манифеста
  (они у озвучки) краткому содержанию не нужны, манифест не меняется.
- `pageCaptions` на миг включает субтитры плеера, если токена ещё нет. Это уже так в озвучке,
  пользователь видит мигание субтитров.

### Как удалить модуль

Без изменений: у `summary/` — папка, строка импорта, строки в popup; у `dub/` — папка, строка
импорта, записи в манифесте. `src/lib/youtube-captions.js` — общий код, остаётся, пока он нужен
хоть одному модулю.

## Этап 1. Краткое содержание видео

### Что видит пользователь

- На странице видео кнопка «Краткое содержание» в popup открывает панель «Краткое содержание
  видео»: «Загружаю субтитры…», потом как у страницы — «Читаю…», стрим ответа, «Коротко /
  Подробно», «Копировать», вопросы.
- Внизу панели — сколько учтено и какие субтитры: «Учтены все субтитры · Субтитры: автоматические,
  en».
- Видео без субтитров — «У видео нет субтитров — сокращать нечего», поле вопросов скрыто.
- Пункт меню «Краткое содержание страницы» на странице видео делает то же.
- Озвучка работает как раньше.

## Этап 3. Кликбейт

После краткого содержания видео модель проверяет, выполняет ли видео обещание своего названия.
Кликбейт — в шапке панели жёлтая плашка «Кликбейт!». Нет плашки — видео названию более-менее
соответствует.

| Вопрос | Решение |
|---|---|
| Когда | Автоматически, после первого готового краткого содержания видео в панели. Один раз на панель: «Коротко / Подробно» вердикт не меняют. Не получилось (ошибка, «Стоп») — молча, без плашки; проверка повторится после следующего готового краткого содержания. Краткое содержание обрезано (упёрлось в `num_ctx`) — не проверяем: вопрос вдогонку не влезет в контекст |
| Что считаем кликбейтом | Название обещает то, чего в видео нет, вводит в заблуждение о том, что это за видео, или преувеличивает так, что зритель почувствовал бы себя обманутым. Броское или эмоциональное название и умеренное преувеличение — не кликбейт. Вердикт один: кликбейт или нет |
| По чему судим | Название, расшифровка (у длинного видео — заметки по частям, они уже в кэше) и готовое краткое содержание. Превью и описание не смотрим |
| Модель | Та же, что в настройках |
| Запрос | Продолжение запроса краткого содержания: те же system и user, потом краткое содержание ответом модели и вопрос о названии. Начало запроса то же — Ollama не разбирает текст заново. Ответ — JSON по схеме, поля по порядку: что обещает название, что в видео, кликбейт ли (`true`/`false`) |
| Видео длиннее предела | Учтено только начало — не проверяем: развязка может быть в конце |
| Объяснение | Только в подсказке при наведении на плашку. Вердикт любого видео, и не кликбейта тоже, — в консоли service worker (`console.debug`) |
| Страницы и выделенное | Не проверяем |

Порт: панель → `clickbait { text, title, length, summary }` → `result { clickbait, reason }`;
`length` и `summary` — у какого краткого содержания вопрос.

Меняются: `src/summary/lib/prompt.js`, `src/summary/background.js`, `src/summary/panel.js`.
